Try these steps on Linux Chromium

Chromium on Linux sometimes can’t use the GPU even when one is installed. Starting a separate Chromium window with experimental WebGPU flags can help.

  1. Open a terminal and run:
    Terminal
    chromium \
  --user-data-dir=/tmp/qni-webgpu-hardware \
  --ozone-platform=x11 \
  --enable-features=Vulkan,WebGPU,WebGPUService \
  --enable-unsafe-webgpu \
  --ignore-gpu-blocklist \
  http://127.0.0.1:4174/
  2. If Qni opens in the new window, it’s working. For Google Chrome, replace chromium with google-chrome.
  • This uses a separate profile, so your everyday Chromium profile stays untouched.
  • These flags relax browser safety checks. Use this window only for Qni on your own machine (localhost), not for other websites.
